Install or replace manually

  1. Choose your exact platform and architecture. Read its release notes and minimum OS requirement before downloading. Windows minimums use the NT version/build tuple (for example, Windows 11 still uses 10.0 builds). This page does not detect your OS or installed version.
  2. Download the ZIP using your browser. Compare its exact byte size and SHA-256 with the published values before extracting. On macOS, run shasum -a 256 "/path/to/archive.zip"; in Windows PowerShell, run Get-FileHash "C:\path\to\archive.zip" -Algorithm SHA256. Hexadecimal letter case does not affect the comparison. A displayed checksum alone does not verify your downloaded file.
  3. Quit the running app. On macOS, extract and replace Dictation.app in your Applications folder. On Windows, extract to a new portable folder and replace the old folder as a whole, keeping bundled models and license notices. Update shortcuts if the folder moved.
  4. Launch the new copy and follow its permission/setup prompts. Downloads, installation and replacement are never automatic.

Existing installations need one manual upgrade to a checker-enabled build to discover future stable releases. Prereleases are excluded from this feed.

This page requests only the static release feed. No recordings or transcripts are sent. GitHub receives ordinary HTTPS request metadata. There are no analytics, third-party scripts or account sign-in requirements.
